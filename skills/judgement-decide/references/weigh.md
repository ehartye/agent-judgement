# Weigh

Sort what you know, look outside, then rate one criterion at a time.

## Sort the evidence

Put each piece in one of four bins and say which option it helps or hurts:

| Bin | Means | Needs |
| --- | ----- | ----- |
| `fact` | Someone can point at it | A source a person could open |
| `inference` | Worked out from facts | Which facts |
| `assumption` | Taken as true | What happens if it is wrong |
| `unknown` | Nobody here knows | Goes to the plan if it could change the choice |

Open a source before recording it as a fact. A summary of a source, or a note that something was
done, is not the thing itself. Collect for and against on every option, the favourite included. An
option with nothing against it has not been looked at yet.

When several people know different things, pool the facts first and score second. Sharing facts does
not by itself change a choice.

## Look outside

Ask: **when others faced this, how did it go?** Find the closest group of cases, what usually
happened, and the source. Record it as `outsideView`, and ask what makes this case truly different.

## Rate

1. Take one criterion. Rate every option on it, 1 to 5, with a short reason that cites evidence.
   Then take the next.
2. Start each criterion with a different option so nobody is always first.
3. Do not add up a total. Lay the table out and look at it.
4. An option that fails a `must` is set aside now, with the reason.
5. Say which rating, if it moved by one, would change the picture. That is where to look harder.
